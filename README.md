# AI 趨勢資訊自動整理與寄送

使用本機 n8n 讀取 Google AI 官方 RSS，整理近期 AI 資訊，並透過電子郵件寄送繁體中文摘要的自動化作品。

## 工作流程

排程或手動啟動 → 讀取 RSS → 篩選近 7 天文章 → 依文章連結排除先前處理過的項目 → 彙整文章 → 使用 Google Gemini 根據 RSS 標題與摘要整理重點 → 寄送電子郵件。

## 使用工具

- n8n
- Google AI 官方 RSS
- Google Gemini API
- Gmail SMTP

## 完成與驗證狀態

- 已完成手動執行與測試郵件寄送。
- 已測試依文章連結排除重複項目。
- 每週三 21:00（台灣時間）的排程已發佈；首次自動執行仍待驗證。

## 執行條件與限制

此工作流程在本機執行，因此電腦與 n8n 必須在排程時間保持運作。沒有符合條件的新文章時，不會寄送郵件。摘要依 RSS 提供的標題與摘要產生，並非讀取全文後的摘要。
